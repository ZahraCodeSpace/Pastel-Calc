# 🧮 Pastel Calc

### A Simple Calculation, A Beautiful Experience.

A modern and elegant calculator built with **HTML, Tailwind CSS, and JavaScript**.

Pastel Calc combines essential mathematical operations with a soft pastel color palette, a clean interface, and a responsive layout to create a smooth and enjoyable calculation experience.

## 💻 Getting Started

You can explore the live version or run the project locally.

### Run Locally

Clone the repository:

```bash
git clone https://github.com/ZahraCodeSpace/Pastel-Calc.git
```

Navigate to the project directory:

```bash
cd Pastel-Calc
```

Open the project in your preferred code editor and run it using Live Server or your local development setup.
